# VibeCode Hub

Красивый гайд по **Claude Code**: установка на Windows, лимиты, ошибки, токены и кастомизация.

Сайт: после включения GitHub Pages → `https://lemonqqq1.github.io/vibecode-hub/`

## Как включить сайт

1. Settings → Pages
2. Source: **Deploy from a branch**
3. Branch: `main` / folder `/ (root)`
4. Save

Через 1–2 минуты сайт будет доступен.
