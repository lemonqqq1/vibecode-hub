Claude Code почти без лимитов

Честно: безлимита нет. Но есть способы работать часами с настоящим Claude и не упираться в стену.

Как устроены лимиты

Действуют два лимита одновременно: скользящее окно на 5 часов и недельный потолок. Claude Code, чат и Desktop тянут из одного общего пула. На планах Max недельных лимитов два: общий и отдельный для Opus или Sonnet. Точные числа Anthropic не публикует. С 6 мая 2026 пятичасовые лимиты для Pro и Max удвоены, а ограничение в часы пик для Claude Code снято.
