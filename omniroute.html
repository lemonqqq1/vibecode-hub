OmniRoute — подробный гайд

Локальный AI-шлюз для Claude Code и других CLI: один endpoint → много провайдеров, в том числе free-тиры. Это замена «мозга», не настоящий Claude.

Установка Claude Code GitHub

Что это и чего ждать

OmniRoute — open-source роутер на твоём ПК. Claude Code остаётся тем же интерфейсом; отвечает модель провайдера, который ты подключил.

Важно: OmniRoute не делает платный Claude бесплатным. Качество и поведение ≠ официальный Claude. Free-тиры у провайдеров могут требовать регистрацию, одобрение или карту и меняться без предупреждения.

1. Установка

1

Нужны Node.js и Claude Code

node -v
npm -v
claude --version

Claude Code, если ещё нет:

irm https://claude.ai/install.ps1 | iex
2

Поставить OmniRoute

npm (рекомендуется):

npm install -g omniroute
omniroute --version

Docker:

docker run -d --name omniroute --restart unless-stopped --stop-timeout 40 -p 20128:20128 -v omniroute-data:/app/data diegosouzapw/omniroute:latest

Из исходников:

git clone https://github.com/diegosouzapw/OmniRoute.git
cd OmniRoute
npm install
npm run dev
3

Запуск

В отдельном окне терминала (не закрывай):

omniroute

Dashboard: http://localhost:20128 · API: http://localhost:20128/v1

omniroute --no-open
omniroute doctor
omniroute setup

2. Провайдеры и ключ

4

Подключи провайдеров

Dashboard → Providers → Add Provider. Без провайдеров список моделей пустой.

  • Kiro AI — часто без ключа, free Claude-подобные модели
  • OpenCode Free — без ключа
  • Pollinations — без ключа
  • OpenAI / Anthropic / Groq / Gemini — свой API-ключ
5

Создай ключ OmniRoute

Dashboard → Endpoints → создай ключ → скопируй сразу. Это доступ к локальному шлюзу, не к Anthropic.

curl http://localhost:20128/v1/models -H "Authorization: Bearer ТВОЙ_КЛЮЧ"

3. Claude Code через OmniRoute

6

Самый простой способ

Окно 1: omniroute. Окно 2:

omniroute launch

Подставит ANTHROPIC_BASE_URL и токен, проверит сервер, запустит claude.

7

Профили по моделям

omniroute setup-claude
omniroute launch --profile glm52
omniroute setup-claude --only glm,kimi
omniroute setup-claude --dry-run

Профили: ~/.claude/profiles/<имя>/settings.json

8

Вручную

Base URL без /v1. Файл %USERPROFILE%\.claude\settings.json:

{
  "env": {
    "ANTHROPIC_BASE_URL": "http://localhost:20128",
    "ANTHROPIC_AUTH_TOKEN": "ТВОЙ_КЛЮЧ_OMNIROUTE",
    "CLAUDE_CODE_ENABLE_GATEWAY_MODEL_DISCOVERY": "1"
  }
}

Env читаются один раз при старте — после смены перезапусти claude.

4. Каждый день и команды

  1. Окно 1: omniroute
  2. Окно 2: omniroute launch
  3. Dashboard → Monitoring / Logs — куда ушли запросы
omniroute status
omniroute logs --follow
omniroute providers list
omniroute providers test-all
omniroute update
omniroute run claude
omniroute launch-codex

5. Другие инструменты

Cursor / Cline / Continue

Base URL http://localhost:20128/v1, ключ из Endpoints, модель auto.

Codex

omniroute setup-codex затем codex --profile … или omniroute launch-codex.

6. Проблемы

omniroute не находится

Переоткрой терминал. Проверь npm list -g omniroute.

Порт 20128 занят

omniroute --port 3000

Пустой /v1/models

Подключи провайдера в Dashboard.

Claude игнорирует шлюз

URL без /v1, перезапуск claude.

Качество «не Claude»

Ожидаемо: отвечает upstream-модель.

Диагностика

omniroute doctor
curl http://localhost:20128/v1/models -H "Authorization: Bearer КЛЮЧ"
