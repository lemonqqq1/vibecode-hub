OmniRoute — бесплатный бэкенд для Claude Code

Локальный AI-роутер: один endpoint → много провайдеров (Kiro, OpenCode Free, Pollinations и др.). Claude Code остаётся тем же, «мозг» — модели провайдеров. Это не настоящий Claude.

npm install -g omniroute
omniroute
# во втором окне:
omniroute setup-claude
omniroute launch
