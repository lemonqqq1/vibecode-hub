VibeCode Hub

Новый репозиторий готов. Стили (glass UI + анимации) уже в style.css.

Скачай из чата файлы index.html и app.js, загрузи их в корень репозитория (через GitHub web: Add file → Upload), затем:

  1. Settings → Pages
  2. Source: Deploy from a branch
  3. Branch: main, folder: / (root)
  4. Save
