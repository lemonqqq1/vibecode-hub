Старый npm-вариант считается устаревшим. Если ставил так, переход: claude install.

3

Проверь установку

Закрой PowerShell, открой заново и выполни:

claude --version
claude doctor

Не находит команду? Смотри раздел «Ошибки Windows» ниже.

4

Запусти в папке проекта и войди

cd путь\к\проекту
claude

При первом запуске Claude Code предложит войти через аккаунт Claude или API-ключ.

5

Настрой за минуту

/init создаёт CLAUDE.md с описанием проекта. /model выбирает модель. /usage показывает остаток лимитов.

Сторонние бэкенды: OmniRoute и DeepSeek (не Claude)

Это замена, а не настоящий Claude: качество и поведение другие. Роутер хранит твои API-ключи, поэтому читай исходники и используй отдельные ключи с лимитом расходов.

git clone https://github.com/diegosouzapw/OmniRoute.git
cd OmniRoute
npm install
npm run dev

Во втором окне терминала: omniroute setup-claude && omniroute launch. DeepSeek без Claude: npx @deepseek-ai/dsh web.
