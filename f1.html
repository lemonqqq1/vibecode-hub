1

Подготовь аккаунт

Нужна Windows 10 (1809+) или 11 и один из вариантов доступа: подписка Pro/Max, API-ключ с балансом либо аккаунт Team/Enterprise. Бесплатный план Claude.ai Claude Code не включает.

Желательно установить Git for Windows: с ним Claude Code работает через Bash, без него через PowerShell.

2

Установи Claude Code

Выбери свою систему и вставь команду в терминал. Node.js не нужен.

irm https://claude.ai/install.ps1 | iex
curl -fsSL https://claude.ai/install.cmd -o install.cmd && install.cmd && del install.cmd
winget install Anthropic.ClaudeCode

WinGet не обновляет Claude Code автоматически.

curl -fsSL https://claude.ai/install.sh | bash

Для macOS есть и Homebrew: brew install --cask claude-code.
