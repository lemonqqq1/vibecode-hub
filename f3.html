Шпаргалка (.md)

Коротко: скачать и запустить, даже без Opus

Если лучшая модель недоступна на твоём тарифе или быстро съедает лимит, Claude Code всё равно работает на других моделях.

1

Скачай

irm https://claude.ai/install.ps1 | iex
2

Выбери модель, которая тебе доступна

claude --model sonnet

Или внутри сессии: /model. Доступны псевдонимы opus, sonnet, haiku. Sonnet и Haiku расходуют лимит заметно медленнее, для большинства правок кода их хватает.

3

Нет подписки? Используй API-ключ

Создай ключ в Anthropic Console, положи небольшой баланс и войди ключом при первом запуске. Платишь только за использованные токены, лёгкие модели стоят дёшево.

4

Нужны облачные кредиты? Через Bedrock или Vertex

Claude Code умеет работать через AWS Bedrock и Google Vertex AI: так можно тратить пробные облачные кредиты. Настройка описана в официальной документации.

Свой роутер или шлюз (LiteLLM, OmniRoute)

Claude Code можно направить на совместимый шлюз переменными окружения. Так запускаются и другие модели, но это уже не Claude, а замена: качество и поведение отличаются.
